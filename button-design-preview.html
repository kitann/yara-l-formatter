YaraLint Button Style Directions

These are visual-only options for choosing a button language. Each card shows the same action group in light and dark surfaces so the style can be judged against the current app themes.

1. Polished Solid

Closest to the current app, but a little more dimensional and modern.

1. Polished Solid, Dark

High contrast, practical, and still recognizable as YaraLint.

2. Outline Utility

Quieter and more professional; good if the editor content should dominate.

2. Outline Utility, Dark

Low-glare controls with a security-console feel.

3. Soft Panel

Friendly, calm, and readable. Less command-heavy than solid buttons.

3. Soft Panel, Dark

Comfortable for long sessions, with enough separation to scan quickly.

4. Left Rail

A tidy enterprise-tool style: restrained with a clear action marker.

4. Left Rail, Dark

Subtle, structured, and good for dense analyst workflows.

5. Google Edge

Uses the multicolor edge treatment sparingly, like the SecOps button.

5. Google Edge, Dark

Visually distinct, best used for one or two special actions.

6. Compact Toolbar

Smaller controls for making the top area feel lighter and more tool-like.

6. Pressed Console

More tactile and terminal-like. Strong, but a bit heavier visually.
