# YARA-L Formatter

Free online formatter and beautifier for YARA-L rules.

## Features

- Format YARA-L syntax
- Clean indentation
- Browser-based
- Fast and lightweight

## Usage

1. Paste YARA-L rule
2. Click Format
3. Copy/Download formatted output

## Tech Stack

- HTML
- CSS
- JavaScript
